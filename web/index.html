    1. Download the certificate: your browser saves the local CA to the device (open it from Downloads).
    2. Settings > Security > Encryption & credentials > Install a certificate > CA certificate, then pick the downloaded file (screen lock required). Samsung: Settings > Biometrics and security > Other security settings > Install from device storage > CA certificate.
    3. Close this site's tabs, then reopen this address:

    No more warning on this address - the padlock is green for good.

    How to install it (once per device)
    • Windows: open the downloaded file, then Install > Local Machine > Trusted Root Certification Authorities > Yes.
    • iPhone / iPad: install the profile in Settings, then Settings > General > About > Certificate Trust Settings and enable full trust for the OpenDrop Local CA.
    • Android: open the downloaded file, then Install a certificate > CA certificate (a screen lock is required).
    • macOS: open the downloaded file, add it to the keychain, then in Keychain Access set Trust > Always Trust for the OpenDrop Local CA.
    • Linux: move the file to /usr/local/share/ca-certificates/opendrop-ca.crt, then run sudo update-ca-certificates.
